# Security

Plutus Wire is local-first and should never require users to paste browser
cookies, platform tokens, passwords, private keys, or OpenClaw gateway tokens
into this repository.

Please report security issues privately to the maintainers before opening a
public issue.

## Sensitive Data

Do not commit:

- local state directories
- raw run artifacts
- SQLite databases
- cookies or tokens
- browser profiles
- cloud sync manifests containing private endpoints
